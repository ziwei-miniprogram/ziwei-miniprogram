# 拾光驿 · 星野漫游小程序（MVP 骨架）

## 小程序简介（提审填写真源）

> 改前请勿在其他地方另写一份，避免表述漂移。

**短版（约 120 字，微信小程序简介栏位）**

星野漫游，一个把中国传统星象文化变成日常陪伴的数字空间。星图、节气、二十八宿、非遗星图，配上每日星语、每日三善与城市守护，让人在山水旅程与日常仪式里安放情绪、观照自己。全站内容为传统文化与心理慰藉的娱乐参考，不预示吉凶、不构成任何专业建议。

**长版（约 300 字，渠道资料 / 合作方一页纸）**

见工作区根目录 `星野漫游-对外表述规范.html` 第 03 节。完整词汇对照表同在该文件。

**定位一句话**：以中国传统星象文化为底色的**文旅数字产品**，价值不在预测未来，而在「能共情」——让人在旅程中感悟文化之美、陶冶心灵之美。

---

一个可直接在「微信开发者工具」中运行的微信小程序骨架，覆盖：星图排盘、文旅研学、心灵之旅、精神疗愈、祝福视频制作、私域商城、功德中心、我的。配套商业与技术方案见同目录 `商业方案书.html`；功德系统与社交玩法见 `功德系统与社交方案.html`。

## 二、本地运行（3 步）

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开开发者工具 → 导入项目 → 选择本目录 `ziwei-miniprogram/`。
3. 把 `project.config.json` 里的 `"appid": "touristappid"` 改成你自己的小程序 **AppID**（无 AppID 可用"测试号"，但部分能力受限）。
4. 编译即可在模拟器预览；手机扫码可真机预览。

## 三、上线前必须完成的配置（对照方案书）

| 步骤 | 配置 | 说明 |
|---|---|---|
| 1 | 小程序账号（企业/个体户主体） | 个人主体无法开通支付与部分类目 |
| 2 | 类目选择 | 建议「文娱-文化馆」或「生活服务-咨询」，避免直接"占卜"红线 |
| 3 | ICP 备案域名 + HTTPS | 自建服务器需要；用微信云开发可免备案 |
| 4 | 微信支付商户号 | 商城实物/文旅产品收款（深度内容已改为功德解锁，不涉内容付费） |
| 5 | 内容安全 API | `msgSecCheck`/`imgSecCheck`，用户生成内容必接 |
| 6 | 资质 | 增值电信业务经营许可证（ICP 证）等，详见方案书 |
| 7 | 《用户协议》《隐私政策》 | 小程序内可访问，否则审核不过 |
| 8 | 文旅地图 Key | 腾讯位置服务，用于 LBS 打卡 |

## 四、祝福视频的合成（真视频怎么做）

小程序端 `pages/blessing` 用 canvas 2d 渲染预览帧，MVP 先导出封面图到相册。
正式 MP4 视频需在**服务端用 ffmpeg 合成**：

- 已内置云函数示例 `cloudfunctions/genBlessingVideo/`。
- 部署：开发者工具开通「云开发」→ 右键该目录「上传并部署：云端安装依赖」。
- 注意：默认 Node 云函数环境**不含 ffmpeg**，需在 `package.json` 增加静态 ffmpeg 依赖，或改用「自定义云托管/容器」环境安装 ffmpeg。
- 前端调用：`wx.cloud.callFunction({ name: 'genBlessingVideo', data: { templateKey, text, music } })`。

## 五、后端/数据接入建议

- 星图排盘：紫微算法较重，建议放服务端（Node/Python）计算后返回；小程序只负责展示。
- 数据：可用微信云开发数据库，或自建 API（需配 request 合法域名）。
- 支付：微信支付 v3，仅用于商城实物/文旅产品下单→支付→回调发货（内容解锁走功德，不涉及支付）。
- 功德系统：前端 `utils/merit.js` + `app.js` 全局状态；后端可复用 `divination-engine/engine/merit.py` 计算等级与解锁门槛。功德经云开发数据库持久化，严禁充值/提现/交易。
- 统计：接微信自定义分析 / 第三方埋点，做转化漏斗。

## 六、合规提醒（务必重视）

- 定位为"传统文化科普 / 心理慰藉 / 娱乐"，全站加"请勿迷信"免责声明。
- 疗愈不得宣称医疗效果；文旅/商品按对应类目资质上架。
- 生日/姓名属敏感个人信息，需单独授权、加密存储、提供注销入口。
- 具体以微信公众平台最新规则与当地法规为准，上线前咨询专业法务。

## 七、内容实时更新工作流（团队协同）

星图文案、心愿签、塔罗释义、商品与文旅线路等内容，由内容团队在后台更新，**无需发版**即可上线：

1. **内容源**：星象解读数据统一来自 `divination-engine` 的知识库（`engine/knowledge/*.json`），经发布器打成版本化内容包（`dist/`）。
2. **更新闭环**：编辑改 JSON → QA 跑 `ops/check.py`（敏感词+结构校验）→ 合规审核 → 工程 `ops/publish.py` 生成内容包 → 上传 CDN → 云函数读取最新内容包返回 JSON → 小程序渲染。
3. **小程序接入**：页面对应数据走云函数拉取；可每日/启动时轮询 `content_manifest.json` 的 `version`，有新版本静默刷新，实现"实时更新内容"。
4. **质量门禁**：任何内容变更必须经 `ops/check.py` 绿灯（高危词直接拦截），CI 接入后非零退出即阻断发布。
